# Opciones legibles y uniformes del cuestionario

## Alcance

- Todas las preguntas utilizan la misma presentación visual de sus opciones: tipografía legible, espacio suficiente para el texto y área táctil cómoda.
- Las escalas numéricas se distribuyen en cinco columnas a cualquier anchura; las respuestas con texto ocupan una fila completa para evitar recortes o botones desiguales.
- La selección visible, el foco de teclado, las etiquetas y los valores de las respuestas permanecen sin cambios funcionales.
- No modificar el editor de preguntas ni las escalas de puntuación.

## Aceptación

- En móvil y escritorio, las opciones numéricas no se comprimen en diez columnas y los textos largos pueden partirse sin desbordarse.
- Todas las opciones usan el mismo tamaño de letra y altura mínima; el estado seleccionado y el foco siguen siendo visibles.
- `npm test` y `npm run build` terminan correctamente.
