# Escala de prioridades con números enteros

## Alcance

- Las dos preguntas de prioridades de cada área ofrecen una escala visible de 1 a 10 con paso 1, sin valores intermedios de medio punto.
- Las respuestas de prioridades no afectan la puntuación de las áreas.
- La autoevaluación de resultados conserva su escala de 0 a 10, ya que es una vista distinta.

## Aceptación

- `optionsFor` genera diez opciones enteras para las preguntas `*_IMP_01` y `*_CAM_01`, en cada área.
- Los renders del cuestionario mantienen una única selección por pregunta.
- `npm test` y `npm run build` terminan correctamente.
